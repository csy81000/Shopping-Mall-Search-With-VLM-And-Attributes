# Catalog data format

이미지와 속성 텍스트는 1:1로 같은 stem을 사용합니다.

```text
product_0001.jpg
product_0001.txt
```

권장 텍스트 예시:

```text
상품명: 미러리스 카메라
가격: 480000원
브랜드: Example
색상: 검정
카테고리: 디지털/카메라
설명: 15-50mm 렌즈가 포함된 경량 미러리스 카메라
```

텍스트가 없는 이미지는 이미지 임베딩만 사용합니다. 경로는 인덱스에 데이터 루트 기준 상대경로로 저장되므로 다른 컴퓨터에서도 `SHOPPING_IMAGE_ROOT`만 바꾸면 됩니다.
